\section{はじめに}
本ソフトウェア「WingGenerator」は、人力飛行機やUAV向けの翼二次構造（リブ・トラスなど）および加工・治具用データを生成する統合設計ツール群です。

\section{機能概要}
本ツールには以下の主要な機能が含まれています。
\begin{itemize}
    \item \textbf{Batch Wing Mode (翼全体のリブ設計):} 翼長、リブ間隔、翼根・翼端の翼型パラメータに基づいて、翼全体のリブ形状とトラス構造を一括で生成・出力します。
    \item \textbf{4-Axis Foam CAM (フォームコア加工):} 熱線カッター（CNC）を用いてフォームコア材を加工するためのGコードを生成します。
    \item \textbf{Wingtip Fin Gen (翼端フィン設計):} 翼端ウイングレットやフィンの形状を設計・出力します。
    \item \textbf{FEA Analysis (有限要素解析):} 生成したリブ形状に対して、CalculiXを用いた強度解析（応力・変形・接着部反力のシミュレーション）を行います。
    \item \textbf{Weight Calculator (重量計算):} 各部材の材質・密度から、リブ全体の重量を算出します。
\end{itemize}

\section{使用方法とパラメータ詳解}

\subsection{起動}
コマンドプロンプトやターミナルで以下のコマンドを実行し、ランチャーを起動します。
\begin{lstlisting}[language=bash, frame=single]
python main.py
\end{lstlisting}

\subsection{Batch Wing Mode (一括生成モード)}
翼の寸法や翼型を指定することで、すべてのリブを一気に設計・プレビューできるメイン機能です。

\subsubsection{Wing Layout (翼全体レイアウト)}
\begin{itemize}
    \item \textbf{Wing Span (mm):} 翼の片側のスパン長（半スパン）を指定します。
    \item \textbf{Rib Interval (mm):} リブを配置する間隔を指定します。
    \item \textbf{Washout (deg):} ねじり下げ角度です。翼根から翼端にかけて、この角度分だけピッチが下がります。
\end{itemize}

\subsubsection{Airfoil \& Chord (翼型・弦長)}
\begin{itemize}
    \item \textbf{Root / Tip Airfoil:} 翼根および翼端の翼型データ（.dat形式）を選択します。UI上でブレンド率（Blend）を指定することで、翼根から翼端にかけて滑らかに翼型を遷移させることができます。
    \item \textbf{Root / Tip Chord (mm):} 翼根および翼端の翼弦長（コード長）です。
\end{itemize}

\subsubsection{Spars (桁設定)}
\begin{itemize}
    \item \textbf{Main Spar Pct (\%):} 主桁の配置位置を翼弦長に対するパーセンテージで指定します（例：30\% であれば前縁から30\%の位置）。
    \item \textbf{Main Spar Dia / dv (mm):} 主桁を通す穴の寸法（直径および垂直方向の長さ）です。
    \item \textbf{Front / Rear Spar Dia (mm):} 前桁・後桁の直径です。使用しない場合は \texttt{0} に設定します。
    \item \textbf{Bolt Holes:} 桁を接合するためのボルト穴です。主桁中心からの相対座標（X, Z）と直径を指定します。
\end{itemize}

\subsubsection{Rib Structure (リブ構造)}
\begin{itemize}
    \item \textbf{Rib Thickness (mm):} リブの厚み（通常のリブの素材厚み）を指定します。
    \item \textbf{Carbon Rib Thick (mm):} 補強用カーボンリブの厚みです。
    \item \textbf{Outer Margin (mm):} リブの外形線からトラス（肉抜き穴）までの余白幅です。
    \item \textbf{Inner Margin (mm):} 桁穴などの周囲に残す余白幅です。
    \item \textbf{Truss Count:} リブ内部をくり抜くトラス（肉抜き）の分割数です。
    \item \textbf{Min Hole Dia (mm):} トラス穴の最小許容直径です。これより小さくなる穴は生成されません。
\end{itemize}

\subsubsection{プレビューと警告機能}
画面右側の「Rib Preview」エリアには、選択したリブの断面形状が表示されます。
\textbf{警告機能：} 翼端に向かって翼弦長が細くなり、主桁穴などの穴がリブの外形線（表面）をはみ出す・交差してしまうような場合は、プレビュー画面上部に赤色の警告ラベル（例：\texttt{WARNING: Main Spar intersects rib boundary!}）が表示されます。

\subsection{FEA Analysis (有限要素解析)}
リブ単体の強度をシミュレーションする機能です。CalculiX (ccxコマンド) を利用します。
\begin{itemize}
    \item \textbf{Lift Dist CSV:} スパン方向の揚力分布データ（Y座標, 揚力N）を読み込みます。flow5等の空力解析結果を利用できます。
    \item \textbf{Allowable Stress (MPa):} リブ素材の許容応力です。これを超えるとUI上で警告（赤い×マーク）が表示されます。
    \item \textbf{Plank (前縁スキン):} プランク材が接着されている場合、その剛性を解析に組み込むことができます。
    \item \textbf{Show RF Arrows:} 桁とリブの接着面に生じる反力（Reaction Force）を矢印ベクトルで可視化するかどうかを切り替えます。
\end{itemize}

\subsection{Wingtip Fin Gen (翼端フィン設計)}
空力解析（flow5等）および製造用の翼端フィンモデルを設計します。
\begin{itemize}
    \item \textbf{Fin Style:} フィンの形状スタイル（Winglet, Horner, Round Dome, Flat）を選択します。
    \item \textbf{Height/Span (mm):} フィンの高さです。
    \item \textbf{Sweep/Offset (mm):} フィン先端の後退量（オフセット）です。
    \item \textbf{Cant Angle (deg):} フィンの傾斜角（カント角）です。
    \item \textbf{Aerodynamic Export:} 画面上の「Export to flow5 (TXT)」ボタンを押すと、flow5に直接インポートできる空力解析用のジオメトリテキストが出力されます。
\end{itemize}

\subsection{4-Axis Foam CAM (フォームコア加工)}
\begin{itemize}
    \item \textbf{Wire Kerf (mm):} 熱線で溶ける幅（カーフ）です。この分だけ軌道が外側にオフセットされます。
    \item \textbf{Tower Distance (mm):} 左右の熱線タワー（ステッピングモーター）間の物理的な距離です。
    \item \textbf{Entry/Exit Strategy:} フォームブロックの外側から熱線が進入・退出する経路の設定です。
\end{itemize}

\subsection{Weight Calculator (重量計算)}
設計データのバウンディングボックス対角線長（3D寸法）やメッシュ体積から、各部品の重量を算出します。
\begin{itemize}
    \item \textbf{Foam Density (g/cm³):} フォーム材の体積密度。
    \item \textbf{Skin Density (g/m²):} 熱線カット時に表面に形成される溶融硬化スキン層の面密度。
    \item \textbf{Carbon Tube Density (g/cm³):} 桁に使用するカーボンパイプ等の密度。
\end{itemize}
\textit{※ストリンガーや斜めスパーなども、テーパー角や後退角を考慮した3次元空間上の正確な長さで計算されます。}
