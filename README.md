# WingGenerator
TBW機特化 翼二次構造生成機

このアプリケーションは、鳥人間コンテスト等の人力飛行機向けに特化した翼の二次構造（リブ・トラスなど）および加工・治具用データを生成するツール群です。

## 動作要件 (Requirements)
本アプリケーションの動作には以下のPythonパッケージが必要です。
事前にインストールしてください。

```bash
pip install numpy matplotlib shapely scipy ezdxf
```
* **Python**: 3.x 環境
* **OS**: 依存はありません（Windows, Mac, Linuxで動作します）

## モード一覧
`main.py` を実行するとランチャーが起動し、以下の4つのモードから選択できます。
1. **Single Rib Mode (単一リブ設計)**: 特定の1枚のリブ形状・トラス配置を詳細に設計します。
2. **Batch Wing Mode (翼全体のリブ設計)**: 翼全体（複数のリブ）を一括で設計・生成します。
3. **4-Axis Foam CAM (フォームコア加工)**: フォーム材の熱線カッター(4軸)用Gコードを生成します。
4. **Wingtip Fin Gen (翼端フィン設計)**: 翼端のウイングレットやフィンの形状を設計します。

## 動作説明：Batch Wing Mode (翼全体のリブ設計)

翼全体に配置される複数枚のリブを一括でパラメトリックに生成・出力するモードです。

### 1. アプリケーションの起動
```bash
python main.py
```
起動したランチャーから **「Batch Wing Mode (翼全体のリブ設計)」** をクリックしてください。

### 2. 基本的なレイアウト設定
「翼全体」タブにて、翼の大枠となるジオメトリ情報を設定します。
* **レイアウト**: 翼長 (Span)、リブの間隔 (Rib Interval) などを入力します。
* **翼根 / 翼端**: 翼の根本および翼端の翼型ファイル（DATファイル等）を指定し、それぞれの翼弦長(Chord)やねじり下げ(Washout)、主桁位置などを入力します。これらを元に、各Y座標におけるリブの形状や角度が自動的に補間計算されます。
* 前縁の円弧補間や後縁カットなどの設定も一括で行えます。

### 3. トラス・肉抜き穴の設計
「リブ」タブにて、リブ内部の肉抜きやマージンの設定を行います。
* **Truss & Margins**: 桁穴、ボルト穴、外周のクリアランス（マージン）を設定します。
* **前縁・後縁トラス**: それぞれの領域に入れるトラスの数（Front Truss N, Rear Truss N）を設定します。
* **個別縮小**: 「前縁トラス個別縮小」「後縁トラス個別縮小」にカンマ区切りで数値（例: `0.7, 0.5`）を入力することで、主桁側から順に肉抜き穴のサイズを個別に調整できます（1未満で縮小、1より大きい値で拡大）。

### 4. 部品・治具のカスタマイズ
他のタブ（XBrace, CFRP Rib, TE_Cap, ジグ等）を用いて、クロスバッツ用の穴、カーボンリブ用の特別設定、後縁材の補強キャップ、リブ組み立て用治具（ジグ）の設定を行うことができます。

### 5. プレビューでの確認
画面右側のプレビューウィンドウには、現在選択しているリブの形状がリアルタイムに描画されます。
プレビュー下部のスライダー（Slider）を動かすことで、翼長(Y軸)方向に沿った各リブの形状変化を連続的に確認できます。
※「FAST PREVIEW」の表示中は演算を軽量化しており、正確な肉抜き形状の確認やDXF出力時には、スライダー移動完了後に自動でフルレンダリングが行われます。

### 6. データのエクスポート (Export)
設定が完了したら、右下の **「Export GLB & DXF」** ボタンを押すことで、各種3Dデータおよび2D加工データが出力されます。
* **GLBファイル**: Blender等で確認できる3Dモデルデータ（3Dプレビュー）。
* **DXFファイル**: レーザーカッター等で加工するための2D図面データ。
* 出力する対象（リブのアウトライン、トラス穴、プランク、治具等）は、Exportボタン上部のチェックボックスから個別にON/OFF可能です。
